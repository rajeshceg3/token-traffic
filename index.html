Prefill is parallel work

The engine reads the prompt together and writes the first KV cache. Long prompts raise the wait before token one.

Decode is sequential work

Each new token depends on the last. Caching avoids recomputing old context, but generation still advances one step at a time.

Serving is a scheduler problem

Continuous batching fills empty seats. Chunked prefill keeps a long prompt from stopping every active decode.
